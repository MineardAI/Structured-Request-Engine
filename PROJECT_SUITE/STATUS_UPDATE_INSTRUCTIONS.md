# Status Update Instructions

## Operational Command

`Run status update.`

## Update Process

Inspect:

- Git state if present
- recent commits if present
- newly added contracts
- modified contracts
- review outcomes
- correction records
- acceptance decisions
- canonization decisions
- dependency-map changes
- artifact-inventory changes
- implementation-plan changes
- source code additions
- test additions
- previous status entries

## Status Language

Status updates must distinguish:

- contract drafted
- contract structurally complete
- contract reviewed
- corrections applied
- contract accepted
- contract canonized
- implementation authorized
- implementation started
- implementation completed
- conformance achieved
- integration completed

## Core Rule

A complete draft is not canonical.
A canonized contract is not implemented.
