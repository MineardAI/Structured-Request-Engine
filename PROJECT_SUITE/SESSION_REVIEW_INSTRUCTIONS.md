# Session Review Instructions

## Operational Command

`Run session review.`

## Review Questions

At the end of a work session, determine:

- what was requested
- what repository evidence was inspected
- what files changed
- whether constitutional authority changed
- whether contract status changed
- whether contract ownership changed
- whether artifact definitions changed
- whether interpretation authority expanded
- whether ambiguity or assumptions changed
- whether provenance changed
- whether failure semantics changed
- whether dependencies changed
- whether canonization occurred
- whether implementation was created
- whether status requires updating
- whether governance review is required

## Drift Checks

Explicitly check for:

- constitutional drift
- contract-scope drift
- transformation-ownership drift
- artifact drift
- interpretation-boundary drift
- objective drift
- constraint drift
- ambiguity drift
- assumption drift
- provenance drift
- canonicalization drift
- failure-semantics drift
- dependency drift
- downstream-authority drift
- implementation-status inflation
