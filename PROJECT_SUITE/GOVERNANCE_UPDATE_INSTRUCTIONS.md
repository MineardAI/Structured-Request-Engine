# Governance Update Instructions

## Operational Command

`Run governance update.`

## Review Scope

Evaluate:

1. constitutional alignment
2. contract identity
3. one-transformation ownership
4. input and output clarity
5. artifact authority
6. interpretation boundary
7. objective preservation
8. constraint preservation
9. ambiguity handling
10. assumption handling
11. provenance preservation
12. canonicalization boundary
13. failure semantics
14. determinism
15. dependency integrity
16. downstream authority separation
17. sparse-repository discipline
18. implementation readiness

## Output

Use the following sections:

- Governance Verdict
- Repository Maturity
- Constitutional Alignment
- Contract Status Findings
- Transformation Ownership Findings
- Artifact Findings
- Interpretation Boundary Findings
- Objective and Constraint Findings
- Ambiguity and Assumption Findings
- Provenance Findings
- Canonicalization Findings
- Failure and Determinism Findings
- Dependency Findings
- Downstream Authority Findings
- Sparse-Repository Findings
- Implementation Readiness
- Required Corrections
- Non-Blocking Recommendations

## Verdicts

- PASS
- PASS WITH NON-BLOCKING CORRECTIONS
- CONDITIONAL PASS
- REVIEW REQUIRED
- FAIL
