## Register rules

- A decision becomes adopted only through an identifiable governing source or formal implementation decision record.
- Normative requirements and implementation choices must remain distinct.
- Transport serialization is not the constitutional canonical representation unless a governing source explicitly requires it.
- Each implementation slice must reference the applicable decision IDs without using this register to create authority.

## Observability review

The governing boundary test is:

> A decision belongs in implementation only if different conforming implementations may choose different mechanisms while still producing equivalent externally observable constitutional behavior.

Different internal mechanisms with equivalent externally observable constitutional behavior are permitted implementation variation. Different externally observable constitutional behavior is not an arbitrary implementation choice.
