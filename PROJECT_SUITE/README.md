# Structured Request Engine Project Suite

This directory is the repository-local NullBlade Project Suite for Structured Request Engine.

It exists to help a future agent navigate the contract system without inventing missing architecture.
The suite is operational documentation only; it is not part of the normative contract set.

## Commands

- `Run session review.`
- `Run opening session review.`
- `Run closing session review.`
- `Run source pack update.`
- `Run status update.`
- `Run governance update.`
- `Run specification review.`

## Authority Model

- Contract 000 is the constitutional source.
- Contract 001 is a draft subordinate contract under constitutional development.
- The planning record is planning, not authority.
- The Source Pack is derivative and non-authoritative.

## Reading Order

Use `PROJECT_SUITE/SOURCE_INDEX.md` first, then `PROJECT_SUITE/STATUS_CURRENT.md`.
When you need detail, follow the source index into the contract files themselves.
