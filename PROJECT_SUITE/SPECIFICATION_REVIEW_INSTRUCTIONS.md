# Specification Review Instructions

## Operational Command

`Run specification review.`

## Review Standard

The review applies to contracts and contract drafts in the Structured Request Engine repository.

Determine whether a contract is:

- constitutionally aligned
- transformation-bounded
- artifact-complete
- provenance-preserving
- ambiguity-aware
- deterministic where required
- failure-complete
- implementable
- testable
- dependency-consistent

## Review Topics

- contract identity
- purpose
- owned transformation
- prohibited authority
- canonical inputs
- canonical outputs
- preconditions
- artifact structure

- assumptions
- ambiguity

- normalization
- validation
- commitment
- failure behavior
- determinism
- replay
- compatibility
- dependencies
- handoff
- invariants
- conformance requirements

## Calibration Warnings

Flag terms such as:

- understands
- infers
- resolves
- canonical
- valid
- complete
- equivalent
- same request
- necessary capability
- reasonable assumption
- successful interpretation

unless operationally defined.
